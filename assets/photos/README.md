# Ảnh của từng người

Chép ảnh vào thư mục này với đúng tên:

| Người | Tên file |
|---|---|
| Mẹ Chinh | `me-chinh.jpg` |
| Tâm Đoan | `tam-doan.jpg` |
| Hải Đoan | `hai-doan.jpg` |

- Đuôi `.jpg`, `.jpeg`, `.png` hoặc `.webp` đều được (trang tự tìm).
- Ảnh sẽ được cắt tròn, nên chọn ảnh có mặt ở giữa. Ảnh vuông khoảng 800×800, dưới 500 KB là tải nhanh nhất.
- Chưa có ảnh thì trang hiện bông hoa thay thế, không bị lỗi.
